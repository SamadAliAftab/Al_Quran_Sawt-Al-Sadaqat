# Al-Quran: Sawt-Al-Sadaqat — Public Media Assets

This repository serves as the official public asset host for the **Al-Quran: Sawt-Al-Sadaqat** mobile application. It hosts downloadable media files and resources required for in-app asset management and content delivery.

---

## 📌 Project Overview

To keep the primary application lightweight and optimize initial app download size, audio recitations, data files, and high-resolution assets are hosted here and fetched dynamically by the app.

* **Purpose:** Asset hosting, media delivery, and remote content storage.
* **Target Application:** Al-Quran: Sawt-Al-Sadaqat (Mobile)
* **Access Type:** Public read-only access for in-app downloads.
