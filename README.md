# Al-Quran: Sawt-Al-Sadaqat

### القرآن: صوت الصداقت

> **A free and ad-free Qur'an application created with care, for the sake of Allah.**

**Al-Quran: Sawt-Al-Sadaqat** is a Qur'an mobile application bringing together multiple widely used Qur'anic layouts, recitation resources, translations, and learning tools in one place.

The name **Sawt-Al-Sadaqat (صوت الصداقت)** is a tribute to **Qari Syed Sadaqat Ali**, whose Qur'anic recitation is featured in the application.

---

## 📖 About the Application

The goal of this project is simple:

**To provide a complete, clean, and accessible Qur'an reading and listening experience without advertisements.**

The application brings together different Mushaf layouts and related Qur'anic resources so that users can access their preferred reading format without needing several separate applications.

The app is intended to remain **100% free and completely ad-free**, In Sha Allah.

---

## ✨ Key Features

* 📖 Multiple Qur'an Mushaf layouts
* 📄 13-line, 15-line and 16-line layouts
* 📚 Additional Qur'an PDF resources
* 🎙️ Qur'an recitation by **Qari Syed Sadaqat Ali**
* 🔊 Urdu translation audio with offline listening
* 📝 **Qur'an Word Guide — Learn Essential Qur'anic Vocabulary**
* 📑 Surah List and Parah/Juz List
* 🕋 Makkah and Madinah Surah information
* 🔖 Bookmarks and Favourites
* ▶️ Audio playback controls
* 🔎 Easy navigation and search
* 🌙 Light and Dark themes
* 🎨 Reading and display customization
* 📱 Designed for mobile and tablet devices
* 🚫 No advertisements

## 📚 Qur'an Word Guide

The **Qur'an Word Guide** is designed to help users learn and recognize essential Qur'anic vocabulary.

Its purpose is to make frequently encountered Qur'anic words easier to recognize during recitation and, ultimately, help users develop a deeper understanding of the Qur'an.
